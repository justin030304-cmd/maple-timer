# Maple Watch

메이플스토리 개인용 화면 타이머입니다. React 19 + TypeScript 5.9 + Vite 7로 구성하며, 흰 배경과 큰 글자의 한국어 인터페이스를 제공합니다. 실제 화면 공유를 연결하기 전에는 대기 화면을 표시하며, 합성 화면이나 가상 감지 이벤트를 생성하지 않습니다. 화면 공유 영상과 분석은 브라우저 안에서만 처리합니다. 별도 백엔드, API 키, 게임 설치 경로는 필요하지 않습니다.

## 실행

Node.js 20.19 이상(20.x) 또는 22.12 이상을 사용하세요. 현재 개발 환경은 Node.js 24입니다.

```sh
cd /workspace/maple-timer
npm ci
npm run dev
```

Chrome에서 `http://localhost:5173`을 엽니다. 다른 장치나 원격 환경에서 접속할 때는 HTTPS가 필요합니다. `getDisplayMedia()`는 보안 컨텍스트와 사용자의 화면 공유 승인이 필요하며, 공유할 창은 Chrome의 선택창에서 직접 선택합니다.

처음 의존성을 구성하거나 `package.json`을 변경한 경우에는 `npm install`을 사용합니다. 제한된 환경에서 npm 기본 캐시 경로에 쓸 수 없다면 `npm ci --cache /tmp/maple-npm-cache`를 사용하세요.

`npm ci`의 설치 후 단계에서 Tesseract.js의 Worker·WebAssembly·영문 숫자 인식 모델을 `public/ocr/`에 준비합니다. 개발 서버 시작과 빌드 전에도 같은 준비 단계가 실행됩니다. 설치 스크립트를 생략했다면 `npm run prepare:ocr`를 직접 실행하세요. 게시 사이트는 이 정적 파일을 같은 사이트 주소에서 내려받아 브라우저 안에서 OCR을 실행하며, 외부 OCR 서버나 런타임 CDN을 사용하지 않습니다.

```sh
npm run build       # TypeScript 검사 + 배포 파일 생성(dist/)
npm run preview     # 빌드 결과 확인
npm test            # 단위 테스트
npm run test:e2e    # Playwright 브라우저 테스트
```

브라우저 테스트는 사용 가능한 시스템 Chromium을 사용합니다. Chromium이 없는 환경에서는 `npx playwright install chromium`으로 Playwright 브라우저를 설치한 뒤 실행하세요. 실제 화면 공유 선택창은 수동 확인도 필요합니다.

## 같은 사이트 주소로 자동 배포

`.github/workflows/deploy-pages.yml`은 `main` 브랜치에 푸시할 때마다 의존성 설치 → 단위 테스트 → 빌드 → GitHub Pages 배포를 실행합니다. 실패한 테스트나 빌드는 배포되지 않습니다. GitHub의 Actions 화면에서 수동 실행도 가능합니다.

현재 저장소는 공개이며, **Settings → Pages → Build and deployment → Source**가 **GitHub Actions**로 설정되어 있습니다. 게시 대상 주소는 [https://justin030304-cmd.github.io/maple-timer/](https://justin030304-cmd.github.io/maple-timer/)입니다. Actions의 **Deploy Maple Watch to GitHub Pages** 실행과 `github-pages` 배포가 성공했는지 확인하세요. 설정 파일이 존재하거나 로컬 빌드가 성공한 것만으로는 사이트가 게시된 상태가 아닙니다.

이 대화에서 계속 수정할 때도 같은 저장소의 `main`에 커밋·푸시하면 기존 게시 주소로 새 버전이 배포됩니다. 파일을 로컬에 저장한 순간에는 배포가 시작되지 않으며, 푸시한 커밋을 기준으로 반영됩니다. 자동 배포가 완료된 뒤 사이트를 새로고침해 새 버전을 확인하세요. Vite의 상대 에셋 경로 설정으로 저장소 이름이 포함된 Pages 경로에서도 실행할 수 있습니다.

동기화되는 것은 사이트 코드입니다. 알림·버프·ROI 설정은 각 브라우저의 `localStorage`에 저장되므로 다른 기기나 다른 사이트 주소로 자동 동기화되지 않습니다. 영상과 캡처 프레임은 게시 이후에도 브라우저 안에서만 처리합니다.

## 사용 방법

1. **화면 공유 시작**을 누르고 Chrome에서 게임 창 또는 화면을 선택합니다. 연결하기 전에는 공유 대기 상태이며, 연결된 실제 영상만 미리보기에 표시됩니다.
2. 룬·버프·경험치·부스터를 각각 켜거나 끕니다. 사용할 모듈의 ROI 편집을 선택한 뒤 영상 위를 드래그해 분석 영역을 지정합니다. 룬은 미니맵만 좁게 지정하세요. 선택 영역은 이동하거나 다시 그릴 수 있고, 좌표를 수치로 조정할 수도 있습니다.
3. 룬 모듈이 켜져 있고 공유 화면과 ROI가 있으면 아이콘 후보 감시가 자동으로 시작됩니다. 버프는 여러 개 등록할 수 있습니다. 비약·유니온의 부는 별도 등록 버튼으로 샘플 기반 자동 감시를 시작하며, 다른 사용자 등록 버프와 부스터는 의미 인식 준비 중입니다.
4. 경험치 ROI를 **화면 하단 초록색 경험치 바 안의 흰색 숫자 부분**에 좁게 지정합니다. 화면 공유·켜진 경험치 모듈·ROI가 준비되면 숫자 OCR이 자동 시작됩니다. 모듈 설정에서 같은 숫자가 유지될 때 알릴 대기 시간을 지정하세요.
5. 알림 설정에서 목소리·음량·말하기 속도를 고르고 **알림 소리 테스트** 또는 룬 카드의 **룬 알림 소리 켜기**를 직접 눌러 소리를 활성화합니다. 설정과 등록한 모듈은 현재 브라우저의 `localStorage`에 저장됩니다.

ROI는 영상 크기에 대한 비율로 저장됩니다. 게임 UI 배치나 해상도가 바뀌면 인식 영역을 다시 확인하세요. 화면 공유를 종료하거나 캡처·분석에 실패하면 상태 표시를 확인할 수 있으며, 해당 상태를 성공적인 감지로 취급하지 않습니다.

## 미니맵 룬 아이콘 감시

찾는 대상은 미니맵 안의 **보라·분홍색과 하늘색이 섞인 마름모, 또는 흰 테두리가 있는 보라색 마름모 아이콘**입니다. 참고 이미지의 빨간 사각형은 위치를 가리키는 주석이며 감지 대상이 아닙니다. 색상·대칭·마름모 형태를 확인하는 실험적인 규칙 기반 검출로, 이미지 템플릿과의 정확한 일치나 룬 활성화 여부를 판독하는 기능은 아닙니다.

- 룬 모듈은 기본적으로 켜져 있습니다. 화면 공유와 룬 ROI를 지정하면 목표 초당 4프레임으로 해당 영역만 분석하고, 미리보기에 후보 위치를 표시합니다.
- ROI를 화면 전체가 아니라 **미니맵 부분에 좁게** 맞추고 아이콘 주위에 여백을 남기세요. 큰 영역은 축소되어 작은 아이콘을 놓칠 수 있고, 다른 게임 UI가 포함되면 오탐 가능성이 높아집니다.
- 룬 설정의 **아이콘 최소 크기 (px)**·**아이콘 최대 크기 (px)**는 원본 공유 영상 기준이며 기본값은 5~36px입니다. **일치 기준 (점)**은 기본 70점으로, 40~95점 사이에서 조절합니다. 점수는 색·형태 조건의 일치 정도이며 인식 정확도나 확률이 아닙니다. 설정은 브라우저에 저장됩니다.
- 색 픽셀을 주변으로 일괄 확장하지 않고, 흰 테두리 픽셀을 통해서만 조각을 연결합니다. 어두운 간격을 사이에 둔 지도 선과 룬이 합쳐져 누락되는 경우를 줄입니다. 이 분리 동작은 주변 보라색 선을 포함한 합성 회귀 자료로 검사합니다.
- 후보가 정상 프레임 3개에서 연속 확인되면 **“룬 아이콘 후보가 감지되었습니다. 미니맵을 확인해 주세요.”**라고 한 번 알립니다. 정상 프레임 8개에서 사라진 뒤에만 재감지를 허용하며, 목표 프레임 속도에서 약 2초에 해당합니다. 알림 사이에는 최소 10초 간격을 둡니다. 프레임 읽기·분석 실패는 아이콘이 사라진 것으로 취급하지 않습니다.
- 아이콘 출현은 룬을 실제로 사용했다는 뜻이 아니므로, 후보 감지만으로 15분 쿨타임 타이머를 시작하지 않습니다. 영상과 색상·UI 배율·겹친 표시에 따라 오탐과 누락이 있을 수 있습니다.

검출 규칙은 합성 이미지와 실제 녹화에서 잘라낸 미니맵으로 검사합니다. 2026-10-28 제공 영상의 룬은 보라색 안쪽과 흰 외곽선 사이에 검은 테두리가 있습니다. 아이콘 크기에 맞춰 그 너머의 강한 흰 외곽선을 네 방향에서 확인한 뒤, 회색으로 번진 가장자리도 형태 검사에 포함합니다. 녹화의 룬 출현 전 2장·출현 후 6장, 위치 이동·50/75/100/125% 크기 변경, 실제 재생 중 한 번의 TTS 알림을 검사합니다. 작은 참고 자료에 대한 기능 검증이며 실전 인식 정확도 평가는 아닙니다. 원본 전체 녹화는 사이트에 포함하지 않습니다.

## 경험치 영역 자동 찾기와 작은 숫자 감시

경험치 모듈이 켜져 있고 ROI가 없으면 공유 화면 하단의 연두색 띠와 흰 숫자 행을 찾아 영역을 지정합니다. 저장된 수동 영역은 덮어쓰지 않습니다. 위치나 UI 배율이 바뀌었을 때는 **경험치 영역 자동 찾기**를 누르거나 직접 수정하세요. 하단이 가려졌거나 다른 UI이면 찾기에 실패할 수 있으며, 미리보기로 올바른 숫자 행인지 확인해야 합니다.

기본 **숫자 모양 변화 감시 · 작은 글자용**은 숫자의 밝은 획을 0.5초마다 비교합니다. 초록색 바의 길이와 주변 이펙트는 비교 대상에서 제외합니다. 숫자를 정수로 읽었다고 표시하지 않으며 ‘숫자 영역 확인됨’으로 안내합니다. 숫자 모양이 바뀌면 무변화 타이머를 초기화하고, 설정 시간 동안 유지되면 알림을 보냅니다. 압축 잡음은 허용하므로 아주 작은 획 변화나 움직임을 놓칠 수 있습니다. 영역이 가려지거나 숫자 획을 찾지 못하고, 프레임 간격이 4초를 초과하면 기준을 초기화해 알림을 억제합니다. 이 기능은 실제 사냥 여부를 직접 판정하는 기능이 아닙니다.

제공된 1920×1080 참고 영상의 하단 숫자 행(약 9픽셀 높이)을 추출해 자동 영역 찾기와 모양 비교를 검사했습니다. 저장소 테스트 자료는 개인 정보가 없는 하단 숫자/바 일부이며 원본 영상은 포함하지 않습니다. 해당 영상의 작은 글자는 일반 OCR로 안정적인 숫자 판독이 어려워 모양 감시를 기본으로 사용합니다. 다른 해상도·폰트에서의 정확도를 보장하지 않습니다.

### 선택 가능한 숫자 읽기 · OCR

경험치 카드의 **경험치 인식 방식**을 ‘숫자 읽기 · OCR’으로 바꾸면 아래 방식으로 동작합니다. 방식 선택은 localStorage에 저장합니다.

경험치 감시는 **읽힌 경험치 숫자의 변화**를 비교합니다. ROI에는 하단 경험치 바의 흰 숫자와 백분율 표시만 포함하고, 화면 전체·HP·MP·움직이는 장식은 제외하세요. 예를 들어 `586,571,406,212,585 [67.391%]`처럼 표시된다면 절대 경험치 값을 우선 사용합니다. 긴 정수도 JavaScript 숫자로 반올림하지 않고 정규화한 문자열로 비교합니다. 절대값을 읽을 수 없을 때에는 `%`가 명시된 백분율을 대체값으로 사용할 수 있습니다.

- 화면 공유와 ROI가 준비되고 경험치 모듈이 켜져 있으면 자동으로 로컬 OCR을 시작합니다. 처음에는 같은 사이트의 Worker·WASM·모델 파일을 불러오는 준비 시간이 필요할 수 있습니다.
- 충분한 판독 신뢰도를 가진 같은 값을 2회 확인한 뒤 기준값으로 사용합니다. 확정된 숫자가 바뀌면 무변화 타이머를 새로 시작하며, 숫자는 같은데 초록색 바나 주변 효과만 움직이는 경우에는 재시작하지 않습니다.
- 같은 숫자가 설정한 시간 동안 유지되면 TTS 또는 기본 알림음으로 한 번 알립니다. 알림음을 사용하려면 먼저 소리 테스트로 활성화해야 합니다.
- 판독 불가·낮은 신뢰도·오래된 판독 결과를 숫자가 멈춘 증거로 취급하지 않습니다. 해당 상태에서는 정체 알림을 억제하고, 읽을 수 있는 상태로 돌아오면 새 기준값부터 다시 확인합니다. 프레임 오류나 OCR 준비·실패 상태는 화면에서 확인할 수 있습니다.
- 모듈에 현재 읽은 값과 OCR 상태·판독 신뢰도를 표시합니다. 신뢰도는 OCR 엔진의 내부 점수이며 실제 게임 인식 정확도나 경험치 획득 판정의 확률이 아닙니다.

Tesseract.js 7과 npm에 포함된 `@tesseract.js-data/eng` 모델을 사용하는 **실험적인 숫자 OCR**입니다. 게임 글꼴·해상도·숫자 배경·UI 배율과 압축 상태에 따라 오독과 누락이 있을 수 있습니다. 제공된 실제 게임 스크린샷 원본 픽셀과 글꼴을 기준으로 정확도를 검증한 결과는 아닙니다. 인식 값이 실제 표시와 맞는지 확인하고 ROI를 조정하세요.

## 한국어 음성 알림

기본 알림 방식은 한국어 TTS 음성입니다. 브라우저의 Web Speech API를 사용하며, 설치된 한국어 음성 중 여성 목소리로 알려진 이름을 우선 선택합니다. API가 성별 정보를 제공하지 않으므로 실제 성별이나 여성 음성의 제공 여부를 보장하지 않습니다. **알림 음성** 목록에서 직접 선택하고 테스트로 들어보세요. 빈 선택값은 자동 선택이며, 저장한 음성이 현재 기기에 없으면 사용 가능한 한국어 음성을 다시 선택합니다.

- 알림 방식을 **한국어 TTS 음성** 또는 **기본 알림음**으로 선택할 수 있습니다.
- 음량은 0~100%, 말하기 속도는 0.7~1.3배로 조정하며, 음성 선택과 함께 저장됩니다.
- 한국어 음성이 없거나 음성 재생이 실패하면 사유를 화면에 표시하고 기본 알림음으로 대신 알립니다. 필요한 경우 운영체제에 한국어 음성을 설치하세요.
- 브라우저의 자동 재생 정책 때문에 먼저 **알림 소리 테스트** 또는 **룬 알림 소리 켜기**를 눌러야 합니다. 기기·브라우저에 따라 음성 목록이 늦게 표시될 수 있습니다.
- 음소거하면 화면 알림은 유지하고 소리·음성 안내를 중단합니다. 실제 스피커 출력과 목소리는 사용하는 기기에서 확인해야 합니다.

일부 브라우저·운영체제 음성은 온라인 서비스를 사용해 알림 문구를 처리할 수 있습니다. 기기 음성을 선택하면 로컬 음성 엔진을 사용할 수 있습니다. 어떤 음성을 선택하더라도 게임 영상이나 캡처 프레임을 TTS 서비스에 보내지 않습니다.

## 실제 인식의 범위

백그라운드 탭에서는 브라우저가 타이머와 프레임 처리를 지연할 수 있습니다. 탭이 닫히거나 절전 상태가 되면 알림을 보장할 수 없습니다. 이 버전은 게임 내 판단을 대신하는 도구가 아닙니다.

## 개인정보와 구현 경계

- 공유 영상·캡처 프레임은 서버에 업로드하지 않습니다. 분석은 로컬 `<video>`와 Canvas에서 수행합니다.
- OCR용 ROI 이미지는 브라우저의 로컬 Worker에서 처리합니다. 같은 사이트에서 정적 OCR 파일을 다운로드할 뿐, 게임 영상·프레임을 OCR 서비스로 보내지 않습니다.
- 화면 공유는 사용자가 시작하고 종료합니다. 새로고침 후에는 다시 승인해야 합니다.
- 게임 메모리 접근, 자동 키 입력, 게임 조작, 매크로 기능은 구현하지 않습니다.
- 저장되는 항목은 모듈·ROI·알림 설정이며, 공유 영상 자체는 저장하지 않습니다.

이후 실제 게임 샘플을 확보하면 해상도·UI 배율별 검증 데이터를 마련해 룬 후보 검출과 경험치 숫자 OCR을 평가·개선하고, 버프·부스터 감지를 추가할 수 있습니다. 샘플 기반 검증 전에는 인식 정확도를 주장하지 않습니다.

OCR 정적 파일을 같은 사이트에서 제공하는지도 확인합니다. 합성 이미지나 Canvas 스트림 테스트 통과는 실제 게임 스크린샷의 인식 정확도를 검증한 결과가 아닙니다. TTS 테스트는 브라우저 음성 엔진을 대체하여 한국어 음성 선택과 전달된 문구·음량·속도를 검사하며 실제 목소리나 스피커 출력을 검증한 것으로 취급하지 않습니다. 영상 업로드 요청이나 외부 OCR 서비스 호출이 없는지도 확인합니다. 실제 Chrome 화면 선택창과 게임 창 캡처, 설치된 음성과 스피커 출력은 사용자 기기에서 수동으로 확인해야 합니다.

## 가로형 알림 목록과 영역 선택 창

대시보드는 룬·사냥 멈춤(경험치)·버프·부스터를 가로 행으로 표시합니다. 각 행에서 활성화, 감지 상태, 알림 기준, 선택한 영역 미리보기를 확인하고 제목을 눌러 상세 설정을 펼칠 수 있습니다. 화면 연결은 상단에서 시작하며 기존 수동 좌표 편집도 아래에 유지합니다.

화면 공유 후 각 알림의 **미니맵 영역 선택 / 경험치 바 영역 선택 / 인식 영역 수정**을 누르면 별도 창이 열립니다.

- **영역 선택 / 직접 그리기**: 드래그로 새 영역을 그립니다. 네 모서리를 잡아 크기를 조절할 수 있습니다.
- **이동**: 빈 곳을 드래그하면 화면이 이동하고, 선택 상자 안을 드래그하면 상자가 이동합니다.
- **확대·축소 / 휠**: 최대 600%까지 확대합니다. 포인터 위치를 기준으로 확대해도 원본 영상 좌표로 저장합니다. 화면 맞춤으로 초기화합니다.
- **경험치 바 윗선 클릭**: 클릭한 높이 근처의 연두색 띠와 가장 가까운 숫자 한 줄을 찾습니다. 게임 창이 공유 화면 중간에 있어도 사용할 수 있습니다. 실패하면 직접 그리기로 숫자를 지정하세요.
- 선택 영역의 실제 영상과 좌표를 확인한 뒤 **적용**을 눌러 저장합니다. 취소는 기존 영역을 보존하며, Esc는 선택을 지우고 선택이 없으면 창을 닫습니다.

특수코어·스킬 알림은 포함하지 않습니다. 비약·유니온의 부는 별도 등록하여 실험 인식을 사용할 수 있습니다. 다른 버프·부스터는 준비 중이며 영역을 지정했다고 감지 성공으로 표시하지 않습니다. 화면 선택과 확대·이동은 이 웹사이트의 미리보기에만 적용하며 게임 창이나 키 입력을 조작하지 않습니다.

## 알림 영역별 소리

각 알림 행의 제목을 눌러 펼치면 **이 알림의 소리**에서 TTS·띵동 벨소리·기본 알림음·공통 설정·개별 무음을 선택하고, 개별 음량과 미리 듣기를 사용할 수 있습니다. TTS는 문구와 한국어 목소리도 따로 지정합니다. 같은 종류의 버프를 여러 개 등록해도 소리 설정은 각 행에 저장됩니다.

- 룬 기본값: 한국어 여성 음성 우선, **‘룬 떳어요’**. 제공되는 음성은 기기마다 달라 목록과 미리 듣기로 확인할 수 있습니다.
- 경험치 기본값: **띵동 벨소리**. Web Audio로 두 음을 합성하며 외부 소리 파일이나 서버가 필요하지 않습니다.
- 버프·부스터 기본값: 공통 알림 설정을 사용합니다. 비약·유니온의 부 외의 준비 중인 감지 기능은 소리 설정만으로 활성화되지 않습니다.

실제 음량은 공통 음량 × 개별 음량입니다. 전체 음소거는 모든 알림을 막으며, 개별 무음은 해당 알림만 막습니다. 미리 듣기는 사용자 클릭으로 소리를 확인하고 활성화하는 동작입니다. 화면 공유 전에 한 번 테스트해 주세요. 소리 선택·문구·음성·음량은 기존 ROI와 함께 localStorage에 저장됩니다.

## 비약·유니온의 부 자동 인식 (샘플 기반 실험)

버프 알림 제목 옆 **비약·유니온의 부 등록**을 누르면 두 감시 행이 추가됩니다. 기본 영역은 공유 화면의 오른쪽 위 1/4이며, 각 행에서 버프 목록 부분으로 영역을 좁히거나 위치를 수정할 수 있습니다. 4번째/9번째 칸 번호를 고정하지 않고 아이콘 모습을 찾으므로 목록 재배치 때 다시 탐색합니다. 비슷하게 생긴 옆 비약과 초록색 유니온 아이콘도 비교하여 구분합니다.

Parser/Matcher는 브라우저의 로컬 Web Worker에서 여러 크기의 아이콘을 탐색합니다. 제공된 첫 영상의 두 아이콘과 두 번째 영상의 노란 초 숫자 모양을 참조합니다. 작은 흰색 분 표시를 초로 간주하지 않습니다. 큰 노란 `9:20` 같은 표시는 콜론 두 점을 확인해 9분 20초로 읽고, `920초`로 처리하지 않습니다. 아이콘과 분·초가 확인되면 **아이콘 감지됨**과 읽은 시간을 표시합니다. 남은 시간이 **59초 이하이고 두 번 실제로 감소**하면서 계산된 종료 시점이 일관될 때만 종료 알림 시계를 시작합니다. 59초보다 많이 남았을 때는 아이콘 감지 상태로 기다립니다. 판독 불가·아이콘 재확인 실패·4초 이상 오래된 프레임은 경고 대상에서 제외합니다. 새 버프 적용으로 종료 시점이 늘어나면 새로운 주기로 확인합니다.

기본 알림은 **10초 전**입니다. 종료 예상 시각의 최대 간격이 **3초 이내**이고 알림 기준이 같은 버프는 한 번으로 묶습니다. 연속적으로 가까운 항목을 이어 붙여 큰 그룹으로 만들지 않으며, 잠깐 놓쳤다가 회복한 같은 종료 건도 중복 알림을 억제합니다. 묶음 소리는 그룹에서 먼저 끝나는 무음이 아닌 알림의 소리 설정을 사용하고, 전체 음소거를 따릅니다.

현재 검증 범위는 제공된 영상의 아이콘 분류·숫자 표본, 그리고 해당 모양을 조합한 정상 속도 카운트다운의 브라우저 통합 테스트입니다. 추가로 2026-10-28 녹화의 노란 분·초 덧씌움(`9:20`, `9:03`, `9:16`, `8:59`, `9:12`, `8:55`)을 검사하고, 잘라낸 버프 목록 영상을 워커에 재생하여 두 대상의 시간 표시와 조기 알림 억제를 확인합니다. 새 글꼴 윤곽은 녹화 앞 7개 표본 프레임에서 추출했으며 뒤쪽 표본도 별도로 검사합니다. 이는 소량의 같은 녹화 내 검증이며 실전 정확도 평가가 아닙니다. 첫 영상은 분 표시 상태이며 실제 두 대상 버프가 59→0으로 끝나는 전체 실전 과정은 검증하지 않았습니다. 다른 해상도·색상 필터·아이콘 가림에서는 누락이나 오독이 있을 수 있습니다. 상태 문구와 최근 판독 숫자를 실제 화면과 비교하세요. 일치 점수는 실제 인식 정확도 확률이 아닙니다. 원본 영상은 배포하지 않으며 모델은 잘라낸 아이콘과 숫자 윤곽만 포함합니다. 다른 사용자 등록 버프와 부스터는 기존과 같이 자동 의미 인식 준비 중입니다.

### 상단 중앙 ‘남은시간’ 박스 알림

‘남은시간 알림’은 제공된 영상의 시계 아이콘·‘남은시간’ 글자와 소수점 두 자리의 디지털 초 표시(예: `14.36초`)를 대상으로 합니다. 화면 공유를 시작하면 화면 상단 32%, 가로 중앙 50% 안에서 박스를 자동 탐색합니다. 버프의 59초 이하 판독과는 독립적으로 동작합니다.

- ‘남은시간’ 제목을 눌러 **미리 알림 (초)** 에 N을 입력합니다. 기본값은 **10초 전**입니다. 이 알림의 소리·음량·TTS 문구도 별도로 설정하고 저장할 수 있습니다. **소리 미리 듣기**를 먼저 눌러 브라우저 소리를 활성화하세요.
- 최근 읽은 소수점 초와 자동으로 찾은 박스 미리보기를 표시합니다. 숫자가 실제로 두 번 감소하고 예상 종료 시각이 일치해야 추적을 시작합니다. N초 이하의 첫 정상 관측에서 한 번 알리며, 타이머가 새로 시작되면 다시 준비합니다.
- 자동 탐색이 실패하면 **자동 탐색 · 영역 직접 지정**을 눌러 **시계·‘남은시간’ 글자·숫자·초 단위를 포함한 박스 전체**를 지정하세요. ‘자동 탐색으로 돌아가기’로 수동 지정을 해제합니다.
